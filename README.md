# MarkD

Редактор документов для macOS и Windows. Файл `.markd` переносит текст, таблицы, слои, изображения и оформление; встроенные шрифты не требуют установки.

## Установка

Сборки [MarkD 0.4.3](https://github.com/OleskyBogdanov/MarkD/releases/tag/v0.4.3):

| Платформа | Файл |
| --- | --- |
| macOS Apple Silicon | `MarkD-0.4.3-arm64.zip` |
| macOS Intel | `MarkD-0.4.3-x64.zip` |
| Windows x64 | `MarkD-Setup-0.4.3-x64.exe` |

На macOS распакуйте ZIP и перенесите приложение в «Программы», на Windows запустите установщик. Данные хранятся отдельно от приложения.

Это пакеты для ручной установки: macOS имеет ad-hoc подпись без нотариализации, Windows — без сертификата издателя. ОС может предупредить о неизвестном разработчике. Автообновление в них отключено.

## Работа с документом

- «Новый проект» создаёт КП, «Пустой документ» — лист, «Из шаблона…» — копию без перезаписи шаблона.
- Содержимое редактируется на холсте, форматирование — в верхней панели. «Структура» показывает слои и прокручивает к выбранному элементу. Строки и колонки добавляются рядом с таблицей.
- Добавление относится к текущей странице. Её выбор, операции со страницами и масштаб 25–200% находятся внизу; доступно масштабирование Ctrl+колесом. Продолжения таблицы принадлежат исходной странице, последний лист удалить нельзя.
- Cmd/Ctrl+S сохраняет, Cmd/Ctrl+Shift+S открывает «Сохранить как». Меню «Файл» содержит открытие, копию, шаблон и «Показать файл». Копия/шаблон не меняют рабочий путь и признак изменений.
- Cmd/Ctrl+Z отменяет, Cmd/Ctrl+Shift+Z повторяет, Cmd/Ctrl+D дублирует объект. Сочетания и меню в редактируемом текстовом поле используют его собственную историю; кнопки «Отменить» и «Повторить» в панели работают с документом и сначала фиксируют текущий ввод.
- Каждая настройка оформления отменяется отдельно. Вставка изображения или Excel, удаление выбранных строк/колонок и один жест изменения размеров таблицы отменяются целиком. История хранит последние 100 операций; открытие другого документа её сбрасывает. Выделение, текущий лист и масштаб в историю документа не входят.
- При закрытии или смене документа можно сохранить, отказаться или отменить. Ошибка записи и отмена выбора пути оставляют редактор открытым. Предпросмотр и PDF фиксируют последний ввод.

### Excel

Начиная с 0.4.3 можно заполнить таблицу документа позициями из прайса ДГУ.

1. «Импортировать Excel» слева от «Файл» загружает прайс ДГУ `.xlsx`.
2. «Заполнить таблицу из Excel» открывает выбор листа, товаров, исполнения, АВР и положительного целого количества.
3. Выберите таблицу. Каждой её колонке назначьте №, наименование, единицу, цену, количество, сумму или «Не заполнять». Единица по умолчанию — `шт.`, её можно изменить.
4. Проверьте предпросмотр и нажмите «Готово»: строки добавятся в конец одной операцией Undo.

№ продолжает существующую нумерацию. АВР прибавляется к цене до умножения на количество; цена и сумма содержат `р.`. Подходят и трёхколоночные таблицы; скрытые и заблокированные недоступны. Каталог хранится до закрытия окна, вставленные значения — в документе. Ручная правка цены не пересчитывает сумму. Формат прайса и ограничения: [импорт Excel](docs/excel-import.md).

### Восстановление

Recovery-снимок записывается примерно через секунду после изменения модели; после сбоя его можно восстановить со стартового экрана. Он не заменяет сохранение и может не содержать последние символы. Исходный файл автоматически не перезаписывается.

При сохранении предыдущая версия остаётся в `.markd.bak`: для открытия скопируйте её под новым именем с расширением `.markd`. Профиль обычно расположен в `~/Library/Application Support/MarkD` или `%APPDATA%/MarkD`. Журналы открываются через «Помощь → Показать папку с журналами».

## Разработка

Node.js **24.20.0** из `.nvmrc` (минимум 24.19), npm **11.19.0**.

```bash
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run test:e2e
npm run build
npm run deps:deprecated
```

E2E используют production renderer и временные профили. CI проверяет macOS arm64/x64, Windows x64 и запуск пакетов; установщики находятся в артефактах `installers-*`.

```bash
npm run package:mac
npm run package:win
npm run smoke:win # на Windows после упаковки
```

Результаты — в `dist-package/`: ad-hoc `.app` с автоматическим smoke на macOS, NSIS `.exe` и `win-unpacked/` на Windows. Подписанный канал обновлений требует переходной ручной установки; последующая установка обновления требует согласия, автоматическая установка при выходе отключена.
