# MarkD

MarkD — настольный редактор переносимых документов для macOS и Windows. Проекты сохраняются в формате `.markd` и могут содержать текст, поля, изображения, таблицы и слои.

## Возможности

- редактирование документов формата `.markd`;
- слои с блокировкой, видимостью и переименованием;
- текст, поля ввода, списки, изображения и таблицы;
- настройка цветов, выравнивания, размеров и границ;
- предпросмотр и экспорт в PDF;
- стартовый экран с недавними проектами;
- журналы ошибок в стандартной папке данных приложения.

## Разработка

Требуется Node.js 20 или новее.

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run test:e2e
```

E2E-тесты запускают Electron со скрытым окном и не мешают работе за компьютером.

## Сборка

```bash
npm run package:mac
npm run package:win
```

Готовые установщики публикуются в разделе Releases.
