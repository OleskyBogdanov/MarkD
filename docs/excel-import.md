# Импорт Excel и заполнение таблицы

## Сценарий и каталог

«Импортировать Excel» слева от «Файл» выбирает `.xlsx`; успех показывает
«Заполнить таблицу из Excel». Каталог — в памяти окна до закрытия,
вне документа/Undo: импорт не меняет dirty/revision. Новый успех заменяет
каталог, отмена/ошибка сохраняют прежний. Прайс не входит в `.markd`
и не отправляется наружу; вставленные значения независимы от Excel.

Выберите лист/товары/исполнение/АВР/количество/таблицу/колонки, проверьте
preview, нажмите «Готово». «Отмена»/Escape отбрасывают только черновик.
Смена документа сбрасывает назначение/выбор, сохраняя каталог.
Старая `sessionId` не открывает диалог в новой сессии; параллельный импорт
и конфликт с Save/PDF исключены.

## Формат прайса

Прайс ДГУ: заголовки строки 3, C4/D4 «Открытые»/«Кожух».
Пробелы/переносы/регистр нормализуются; строки 1–2 не товары.
Объединённый C3:D3 не означает отсутствия D.

| Колонка | Смысл |
| --- | --- |
| A / B | Модель ДГУ / марка двигателя |
| C / D | Остаток открытых / в кожухе |
| E / F / G | Номинальная мощность, кВт / кВА; резервная мощность, кВт |
| H | Модель двигателя |
| I | Модель альтернатора |
| J / K | Цена открытой / в кожухе без АВР |
| L / M | Стоимость АВР / ток АВР («Мощность АВР, А») |
| N / O | Габариты открытой ДГУ / в кожухе, мм |
| P / Q | Масса открытой ДГУ / в кожухе, кг |

Параметры показаны отдельными колонками таблицы каталога, включая
остатки, габариты и массу обоих исполнений независимо от выбора.
«Цена, ₽» показывает цену выбранного исполнения; при смене исполнения
она обновляется. Две отдельные ценовые колонки не показываются,
но обе исходные цены сохраняются для расчёта.
Каталог прокручивается по горизонтали и вертикали; заголовки закреплены.
На широком экране при горизонтальной прокрутке видны модель и кнопка выбора.
«На складе» — сумма остатков открытой ДГУ и ДГУ в кожухе, независимо от
выбранного исполнения. Оба раздельных остатка стоят сразу справа от суммы.
Пустой остаток не прибавляется; если оба пусты, сумма показывается как «—».
Явный ноль показывается как 0.
Технические значения сохраняются как текст до 4096 символов с нормализацией
пробелов; пустые показываются как «—», нулевые сохраняются.
Они не меняют наименование и расчёт вставляемой позиции.

Номер строки/J/K/L сохраняются, одинаковые модели не сливаются.
Разделы/подзаголовки/примечания пропускаются, «ИТОГО» завершает товары;
повреждённый товар остаётся с диагностикой. Единственный подходящий лист
выбирается автоматически, несколько — явно.

Контрольный лист «Прайс для дилеров»: 29 товаров; C/J пусты —
открытое исполнение недоступно. D — остаток, не заказ;
K включает НДС 22%, повторного начисления нет. Свободные примечания
не служат источником правил.

## Расчёт позиции

```text
Дизельный генератор {A}{исполнение}{АВР} {B} ({H})
```

Кожух: ` в шумозащитном евро кожухе`, АВР: ` с АВР`.
Без слова «Двигатель»/звёздочек/лишних пробелов, с исходным регистром:

```text
Дизельный генератор AD-20-R в шумозащитном евро кожухе с АВР Ricardo (ZH4100D)
```

Цена — J/K исполнения; пустая не ноль и не подменяется другой,
недоступность объясняется. С АВР `цена = база + L`, затем
`сумма = цена × количество`; без АВР — база.
AD-20-R: K=515899, L=45000, D=3; с АВР 560899 рублей.
Checkbox активен у выбранного товара, сам его не выбирает; снятие выбора
сбрасывает АВР. Неверная/пустая L блокирует АВР.
Модель, марка/модель двигателя, цена обязательны при любом сопоставлении.

Количество — положительное безопасное целое, начально 1.
Деньги — целые копейки, decimal half-up при чтении, допустимы пробелы/
запятая. Пустое/ноль/ошибка различаются; отрицательное/переполнение запрещено.
Цена/сумма всегда с `р.`: `0 р.`, `1 234 р.`, `1 234,05 р.`.

## Таблица и сопоставление

Назначения — исходные `project.pages[].elements`, `type: table`, без
продолжений. Подпись: страница/`pageHeader`/номер при совпадении.
Колонки: первая строка при `firstRowHeader`, иначе «Колонка 1» и далее.

Нужны ≥1 колонки с непустыми уникальными ID, непустые строки с правильным
числом ячеек. Отсутствующий/hidden/locked слой и неверная структура
недоступны с причиной. Чужой visible/unlocked слой активируется
через `setActiveLayer`; store guard `elementIsEditable` не обходится.

Каждому ID колонки соответствует источник:

| Значение | Новая ячейка |
| --- | --- |
| `skip` («Не заполнять») | Пустая |
| `number` («№») | Продолжение нумерации |
| `name` | Наименование |
| `unit` («Ед.») | Редактируемая единица, по умолчанию `шт.` |
| `price` / `quantity` / `total` | Цена / количество / сумма |

Повтор источников разрешён, заполнена ≥1 колонка: одна/три колонки подходят.
Прежние четыре разные колонки/добавление «Сумма» не требуются.
Привязка по ID, смена таблицы пересчитывает её. Заголовки дают предложения,
неизвестные — `skip`; единица после trim — 1–64 символа.

`number` каждой колонки: максимум существующих целых из цифр, без заголовка/
пустых/нечисловых. Далее максимум + 1, без номеров — 1; без переполнения.
Preview/измерение/вставка используют одну проекцию `getExcelRowCells`
в колонки, включая номера/единицы.

## Запись и оформление

«Готово»: `flushPendingEdits`, повторная проверка `sessionId`, таблицы,
структуры/ID, сопоставления, слоя. Ошибка оставляет диалог, без частичной
вставки. Повторное подтверждение блокируется, закрытие только после успеха.

Добавление только в конец по порядку Excel, без заполнения пустых строк/
поиска «Итого». Старые строки/заголовки/колонки/ширины/стили сохраняются;
новые row/cell ID уникальны. Одно `applyHistory`, один dirty/revision,
один Undo всего импорта и Redo.

Высота по проекции/ширинам/базовому шрифту/переносам таблицы — 24–96 px;
далее штатные геометрия/пагинация. Результат — редактируемый текст
в `.markd`/preview/PDF, без пересчёта после ручной правки цены/количества.

## Чтение, формулы и лимиты

Main читает только выбранный `.xlsx`, проверяя происхождение IPC.
Узкий preload передаёт валидированный каталог и имя файла без абсолютного
пути/сырых байтов/произвольного доступа. Отмена возвращает `null`,
ошибки — штатным механизмом.

| Предел | Значение |
| --- | --- |
| Файл / распакованный ZIP | 10 МиБ / 16 МиБ |
| Записи ZIP / листы | 256 / 16 |
| Строки / колонки | 2000 / 32 |
| Ячейки книги | 64000 |
| Значение / XML-атрибут | 4096 символов |
| Глубина XML | 64 |
| Worker | 30 секунд, old generation 128 МиБ |

Размер проверяется до чтения и ограничивается при росте файла;
изменившийся во время чтения файл отклоняется. ZIP-preflight и библиотека
читают одни неизменяемые байты и central directory. Контролируются
заявленный и фактический распакованный объём, размеры потоков, дубликаты
записей, адреса ячеек/dimension/merge ranges. На диск архив не извлекается.
Шифрование и DTD отклоняются. Worker ограничивает библиотечный парсинг.

Формулы не вычисляются, макросы не запускаются. Формула или ошибка Excel
в A–Q отклоняется даже с кешем: нужно заменить значением.
Контракт каталога допускает до 16 листов, 2000 товаров на лист, 16 сообщений
о проблемах товара; суммы/остатки неотрицательны, до
`Number.MAX_SAFE_INTEGER`, отсутствие — `null`.

## Интерфейс и регрессии

Диалог: удержание/возврат фокуса, Tab/Shift+Tab/Space/Escape, имена с моделью,
видимый focus, ошибки у поля. Команды документа блокируются,
нативная история ввода в полях остаётся доступна.
Футер доступен, контент прокручивается вертикально, каталог/preview
горизонтально локально, настройки в узком окне — одной колонкой.

Регрессии: 29 товаров/C3:D3, повреждения/формулы/лимиты, АВР, ноль/копейки,
сопоставление/номера, отмена/сессия/слои, Undo/Redo, reopen/PDF.
Fixtures синтетические, личный прайс не публикуется.
Проверка Mac не заменяет нативный выбор файла и приёмку Windows.
