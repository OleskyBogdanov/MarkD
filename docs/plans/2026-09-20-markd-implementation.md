# Реализация улучшений MarkD — 20 сентября 2026

## Объём

Реализованы локальные исправления и подготовка выпуска из [плана](2026-09-20-markd-improvement-plan.md). Подписанное распространение и фактическое обновление установленного Windows/macOS клиента остаются внешним этапом; его нельзя объявлять завершённым по этим тестам.

## Обновления и сборки

Встроены electron-updater 6.8.9, state controller, типизированные IPC и панель версии/обновления. Проверяются только release-пакеты с build-time HTTPS URL. Загрузка по действию пользователя; auto-install-on-quit выключен. Установка проходит сохранение документа; Cancel блокирует её, ошибка установки возвращает документ в рабочий режим. Unit покрывают отключённый feed, coalescing, сетевую ошибку, Cancel и ошибку установки. Они не проверяют реальную криптографическую проверку/установку пакета.

Созданы verify и release-candidate workflows для macOS arm64/Intel и Windows x64. E2E используют production renderer и переносимые временные пути/репозиторный PNG вместо macOS-only изображения. Local ad-hoc упаковка отделена от signed release. Схема обеих release-конфигураций проверена установленным electron-builder 26.15.3.

Инструкции по сертификатам, HTTPS feed и последовательности публикации — [docs/releasing.md](../releasing.md). Ветка `codex/markd-reliability-updates` опубликована с разрешения владельца. Первый remote CI прошёл полностью на Intel macOS; arm64 и Windows выявили зависимость drag-тестов от прокрутки, а Windows — ограничение частоты кадров скрытого тестового окна. Проверки координат переведены в систему листа, Windows CI запускает обычные видимые окна: `backgroundThrottling=false` уже был настроен, но скрытый compositor всё равно ограничивал обработку ввода. Локально окна остаются скрытыми. После исправлений выполняется повторный remote CI. Подписанный release не запускался.

## Результаты локальной проверки

Среда: macOS arm64, Electron 44.1.1; финальные команды — Node 24.20.0 из `.nvmrc`.

- `npm run typecheck` — успешно.
- `npm run lint` — успешно, без warnings.
- `npm test` — 45 тестов в 8 файлах.
- `npm run test:e2e` — 43 теста, включая 11 новых lifecycle/UX сценариев.
- `npm run deps:deprecated` — точный allowlist; добавлена транзитивная lodash.isequal из updater 6.8.9. npm install сообщил 0 vulnerabilities на момент установки.
- Сборка `.app`, `codesign --verify --deep --strict`, 5 fuses и запуск packaged renderer — успешно, runtimeErrors пуст.
- `git diff --check` — успешно.
- Визуально просмотрены редактор при 1024 px и экспорт PDF. PDF — одна A4-страница, без служебных панелей/кнопок. Артефакты: `output/verification/editor-1024.png`, `preview.png`, `proposal.pdf`, `pdf-page.png` (локальные, не коммитятся).

## Границы проверки и следующие ворота выпуска

Windows runtime/NSIS и Intel runtime на этой машине не запускались. Доверенные сертификаты, нотариализация, сервер раздачи и N → N+1 на реально установленных подписанных версиях не предоставлены и не подтверждены. Нужно запустить подготовленные jobs, проверить результаты и пройти матрицу обновлений из release guide. Для версии без обновлятора потребуется одна переходная ручная установка.

Автоматические OS-specific визуальные baseline пока не утверждены: локальный PDF просмотрен вручную, Windows rendering нужно проверить на Windows. Оптимизация крупных документов и переход с JSON/base64 на ZIP остаются отдельными задачами по результатам измерений; сейчас формат и schemaVersion не менялись. История undo больше не делает лишнюю глубокую копию при перекладывании immutable snapshots, но остальные изменения структуры не выдаются за полную оптимизацию больших файлов.
